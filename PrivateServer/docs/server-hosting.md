# Hosting projects

Hosting settings belong to server configuration. The launcher manages player
setup, selected server, controls, game launch and joined-world history.

- [Inverna hosting project](https://github.com/dr4lera/pokemon-platinum-together-open-sourced-inverna-server): shared city/social deployment.
- [World hosting project](https://github.com/dr4lera/pokemon-platinum-together-open-sourced-world-server): co-op protocol/storage deployment.
- [Configuration reference](server-config.md)
- [Bans and plugin API](moderation-and-plugins.md)

The hosting projects currently exist locally and have not yet been published.
Native guest synchronization, cross-server handoff, unattended simulation and
story/map integration are unfinished. Separate servers currently have independent
identities; moving between them is not automatic world federation.
